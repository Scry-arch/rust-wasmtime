# Trampoline Tests

A set of trampoline functions tested for the exact assembly output

CLIF filetests use a *trampoline* function to setup the execution environment of tests.
The trampolines are generated by the testing framework and are compiled alongside the tested functions.
The trampolines take 2 inputs: the ptr to the tested function and a pointer to an array of paramters to the tested function.
The trampoline loads the parameters and then does an indirect call to the tested function with the parameters.
Each trampoline is therefore specific to the tested functions exact parameters (their number and types).

The functions tested here match specific trampolines generated when testing other functions.
To avoid dependency on other assembly functionality, we only test the generated assembly.
